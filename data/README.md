# Data

Place source data files here, for example:

- `daily_stock_prices.csv` — OHLCV price history per company (2018–2022)
- `company_financials.csv` — annual revenue, net income, total assets, employees per company/year
- `market_index.csv` — daily market benchmark close/return (used for beta calculation)

Matches the model structure documented in `docs/COVID_Market_Impact_Dashboard_Documentation.docx` (Section 4 — Data Model).
